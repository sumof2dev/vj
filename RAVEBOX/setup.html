Sequencer Syntax

                                    
Range: 0-255 (Maps to energy)

                                    
Chain: 32-96-32 (Multi-point sweep)

                                    
Sequence: 127, 255, 0 (Synced steps)

                                    
Offset: 32-96 + 64 (Phase shift)

                                    
                                    
Keywords

                                    
On/Off: on, off, max, min, zero

                                    
Speed: slow, med, fast, punch

                                    
                                    
VisualDMX Targets

                                    
strobe: 0 (Off) to 255 (Fast)

                                    
blackout: 0 (Normal) to 255 (Blackout)

                                    
spin: Coordinate rotation

                                    
feedback: Video feedback intensity
